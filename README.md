# JD 抢购客户端使用说明

这个项目是一个在你自己电脑上运行的京东库存监控工具。它会打开一个本地网页工作台，你在网页里填商品、地区和下单时间，然后让程序帮你检测库存、进入购物车和结算页。

默认是安全模式：程序只会走到京东结算页并找到 `提交订单` 按钮，不会真的点下去。只有你手动打开工作台里的 `自动点击提交订单`，才可能产生真实订单。

## 你需要准备什么

先确认电脑里有这些东西：

- Chrome 或 Edge 浏览器
- Python 3.11 或更新版本
- Node.js 和 npm

如果你不确定有没有安装，可以在终端里分别输入：

```bash
python --version
node --version
npm --version
```

能看到版本号就说明基本可用。

## 第一次安装

打开终端，进入项目目录。

Windows 示例：

```powershell
cd D:\AI\JDPanicBuying
```

macOS / Linux 示例：

```bash
cd /Users/你的用户名/PycharmProjects/JDPanicBuying
```

然后安装 Python 依赖：

```bash
python -m pip install -r requirements.txt
```

再安装并构建前端页面：

```bash
cd frontend
npm install
npm run build
cd ..
```

看到 `built` 或 `✓ built` 之类的提示，就说明页面构建好了。

## 启动客户端

回到项目根目录后执行：

```bash
python runserver.py
```

如果启动成功，终端会出现类似：

```text
http://localhost:12021/
```

不要关闭这个终端窗口。它就是客户端服务。

然后打开浏览器访问：

```text
http://localhost:12021/
```

你会看到“京东库存监控工作台”。

## 正常使用流程

1. 点击 `打开专用京东浏览器`。
2. 在弹出的浏览器里登录京东。
3. 回到工作台，点击 `检查专用浏览器`。
4. 如果提示已经登录，就填写商品链接或 SKU。
5. 填写地区 ID、数量、间隔秒、重试次数。
6. 先点击 `立即检测`，确认商品页能访问。
7. 再点击 `开始自动下单` 或 `启动定时下单`。

第一次使用建议保持 `自动点击提交订单` 关闭。这样程序只会进入结算页，不会真的提交订单。

## 怎么填商品和地区

商品可以填完整链接：

```text
https://item.jd.com/100021044189.html
```

也可以只填 SKU：

```text
100021044189
```

地区 ID 需要按你的收货地址填写，格式类似：

```text
21_1827_4101_40925
```

项目里有一些地区 ID 参考文件：

```text
TEST/area_id
```

## 两种运行模式

`有货自动下单`：适合商品暂时无货，程序循环检测，发现可能可买后自动进入下单流程。

`定时下单`：适合你知道具体开售时间，比如某天 10:00 开抢。

## 关于真实下单

工作台里的 `自动点击提交订单` 默认关闭。

关闭时：

- 程序会尝试进入商品页
- 自动加购或进入购物车
- 自动进入结算页
- 找到 `提交订单` 按钮后停止

开启时：

- 程序会真实点击 `提交订单`
- 可能产生真实京东订单

开启前请确认：

- 商品是你要买的
- 数量正确
- 地址正确
- 价格可以接受
- 购物车里没有不想一起提交的商品

## 常见问题

### 页面打不开

确认启动服务的终端没有关闭，并且里面没有报错。然后重新打开：

```text
http://localhost:12021/
```

### 页面提示前端构建产物不存在

说明还没有构建页面。执行：

```bash
cd frontend
npm install
npm run build
cd ..
```

然后重新启动：

```bash
python runserver.py
```

### 提示没有登录

按这个顺序来：

1. 点击 `打开专用京东浏览器`
2. 在专用浏览器里登录京东
3. 回工作台点击 `检查专用浏览器`

### 商品页出现京东验证

这是京东风控。你需要在专用浏览器里手动通过验证，然后再回工作台重试。

### Windows 想用脚本启动

如果你已经按项目原来的方式创建了 `jd-conda-env`，可以直接运行：

```powershell
.\start_server.bat
```

否则更推荐先按上面的通用步骤安装依赖并使用：

```bash
python runserver.py
```

## 每次以后怎么用

以后不用每次都重新安装依赖。一般只需要：

```bash
python runserver.py
```

然后打开：

```text
http://localhost:12021/
```

如果前端代码更新过，再重新执行一次：

```bash
cd frontend
npm run build
cd ..
```
